Frequently Asked Questions
==========================

What is Toga Chart?
-------------------

Toga Chart is a `Matplotlib <https://matplotlib.org/>`__ backend and widget for
`Toga <https://toga.beeware.org/en/stable/>`__. It lets you embed Matplotlib figures in
a Toga application using the same ``Figure`` and ``Axes`` APIs you would use in
any other Matplotlib application.

What version of Python does Toga Chart support?
-----------------------------------------------

Toga Chart supports Python 3.10 or newer.

Which platforms does Toga Chart support?
----------------------------------------

Toga Chart is implemented using Toga's cross-platform ``Canvas`` widget. Any
platform with a Toga canvas implementation should be able to display a Toga Chart
widget; platform-specific rendering limitations may still apply.
